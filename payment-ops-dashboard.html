Payment Reconciliation
Comparing internal records vs. payment gateway settlement — Oct 2026
Reconciliation Logic:
Each internal transaction record is matched to the payment gateway settlement file by Transaction ID and Reference Number. Amounts are compared against the settlement amount within a ±$0.01 tolerance (for FX rounding). Transactions present in internal records but missing from the gateway log are flagged as Missing. Transactions present in the gateway log but absent from internal records are flagged as Unmatched. Identical TXN IDs appearing more than once are flagged as Duplicate. Settlement dates more than 3 business days from transaction date are flagged as Settlement Delay.

SOP & Operational Controls
Standard operating procedure for daily payment operations workflow
1
Receive & Verify Payment Records
Download the daily transaction export from the payment gateway portal. Confirm the file covers the correct date range. Verify total record count matches the expected volume. Check for file integrity — no truncated rows, correct column headers, no encoding errors. Log receipt timestamp and file hash to the operations log.
Payment Gateway PortalExcel / Google SheetsOperations Log
2
Monitor Transaction Statuses
Review all pending transactions older than 24 hours. Flag any transaction pending more than 3 business days for escalation. Confirm all Successful transactions have a corresponding settlement entry. Document Failed transactions with failure reason codes and categorise by type (insufficient funds, expired card, gateway error, fraud flag).
Transaction DashboardCRM / ERP SystemEscalation Log
3
Compare Internal vs External Records
Load the internal transaction register and the gateway settlement file into the reconciliation tool. Match records by Transaction ID and Reference Number. Apply a ±$0.01 FX tolerance for currency conversion rounding. Flag all unmatched, missing, and duplicate entries for investigation. Document the total matched count and reconciliation completion percentage.
Reconciliation ModuleExcel VLOOKUP / MATCHInternal Ledger
4
Identify & Investigate Discrepancies
For each flagged discrepancy, create a Discrepancy Investigation record with: Reference ID, issue type, amount, date identified, priority (High / Medium / Low), and assigned team. Review available transaction metadata (IP, device, bank response code). Contact the relevant payment processor or bank for clarification where needed. Document all investigation notes and intermediate findings.
Discrepancy TrackerPayment Processor SupportBank Correspondence
5
Escalate Unresolved Issues
Any discrepancy unresolved within 48 hours must be escalated to the Finance Manager. High-priority discrepancies (amount > $1,000 or fraud-related) must be escalated immediately upon identification. Prepare a structured escalation brief including: discrepancy summary, investigation steps taken, amount at risk, and recommended action. Obtain sign-off confirmation from the escalation recipient.
Email / SlackEscalation RegisterFinance Manager
6
Document Findings & Resolutions
Once a discrepancy is resolved, update the Investigation Tracker with: resolution date, outcome (refunded, corrected, voided, bank error confirmed), and any adjustments made to the internal ledger. Retain all supporting documentation (bank statements, gateway screenshots, email correspondence) for audit purposes. Archive resolved cases monthly.
Discrepancy TrackerDocument ArchiveAudit Trail
7
Prepare Daily Reconciliation Report
Compile the daily reconciliation summary: total transactions processed, reconciliation completion rate, outstanding discrepancies, failed transaction count, and executive notes. Submit the report to the Finance Manager by 5:00 PM local time each business day. Flag any unusual patterns or volume anomalies in the report commentary. Archive the completed report with date stamp.
