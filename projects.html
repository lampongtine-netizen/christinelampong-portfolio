Documentation

SOPs that actually get followed.

A sample of the 24 standard operating procedures built across these projects.

SOP-001 · Client Onboarding Process
Owner: Operations Manager · Tools: ClickUp, Notion, Dubsado
  1. Update client status in ClickUp to "Active Client" upon contract signature — triggers automated onboarding task list
  2. Send Welcome Email within 2 hours using approved template with kickoff booking link and Notion access
  3. Complete client profile in Notion — all database fields, signed contract upload, dedicated Slack channel created
  4. Conduct 60-min kickoff call within 5 business days using Kickoff Call Template
  5. Build client's ClickUp project workspace within 24 hours of kickoff, assign team, set milestones
  6. Send "You're All Set" confirmation — project timeline, contact info, ClickUp access. Mark onboarding complete.
SOP-002 · Content Approval Workflow
Owner: Content Manager · Tools: ClickUp, Notion, Loom, Slack
  1. Brief approved in ClickUp — writer tagged, status set to "In Draft," deadline auto-calculated 5 days pre-publish
  2. Internal review by Content Lead within 24 hours — feedback as ClickUp comment, status updated accordingly
  3. Client review package prepared: Loom walkthrough + Notion page, 48-hour review window with 24-hr reminder
  4. Client approves via Notion comment or email — designer finalizes assets within 24 hours
  5. Final QC checklist completed — content scheduled. Status set to "Scheduled."
SOP-003 · Escalation Protocol
Owner: Operations Manager · Tools: Slack, ClickUp, Email
  1. Team member flags task in ClickUp with "Escalation Needed" tag and posts in #escalations Slack channel
  2. Ops Manager acknowledges within 1 hour — categorizes as: ops-level, executive decision, or client-facing
  3. Client-facing issues: holding message sent within 2 hours, ETA committed within 4 hours
  4. Resolution documented in Notion incident log — root cause identified, prevention plan communicated to client
SOP-004 · Weekly Reporting Cycle
Owner: Operations Manager · Tools: ClickUp, Notion, Google Sheets
  1. Monday 8:00 AM: Pull KPI data from ClickUp dashboards, update Google Sheets master KPI tracker
  2. Complete weekly executive summary in Notion — wins, blockers, at-risk items, one headline metric per department
  3. Send report to leadership by Monday noon — flag red metrics with recommended actions
  4. Lead 15-minute Monday Operations Standup — assign action items in ClickUp with owners and due dates
